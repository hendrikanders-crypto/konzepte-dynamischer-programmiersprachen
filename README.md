# Konzepte dynamischer Programmiersprachen

Übungen und Lösungen zum Modul „Konzepte dynamischer Programmiersprachen“ im B.Sc. Informatik (berufsbegleitend) an der FOM.

## Inhalt

| Ordner | Beschreibung |
|---|---|
| `Vorlesungsübungen/` | Lösungen zu den Übungsaufgaben aus der Vorlesung |

## Aufgaben

- **Aufgabe 4a:** Berechnet Volumen und Oberfläche eines Würfels anhand der eingegebenen Seitenlänge a.
- **Aufgabe 4b:** Berechnet Volumen und Oberfläche eines Quaders anhand der eingegebenen Seiten a, b und der Höhe c.
- **Aufgabe 4c:** Berechnet Volumen und Oberfläche eines Zylinders anhand des eingegebenen Radius r und der Höhe h.

## Ausführen

Voraussetzung: Python 3.x

```bash
python Vorlesungsübungen/Vorlesung_Aufgabe_4a.py
```
